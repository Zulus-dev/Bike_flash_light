# Веб-интерфейс Bike Light (ANTARES) — описание всех функций

**Редакция прошивки:** 2.6  
**Точка доступа:** `BikeLight_AP` / `12345678`  
**Адрес:** http://192.168.4.1  
**Файл UI в прошивке:** `src/wifi_web.c` (встроенный HTML + API)  
**Скриншот / макет в проекте:** `web_ui_bike_light.jpg` (концепт-макет Smart Bike Light PRO)

---

## 1. Общий вид и навигация

Заголовок страницы: **ANTARES Bike Light**.

### Статус-бар (обновляется ~каждые 0.8 с с `/api/status`)

| Поле | Описание |
|------|----------|
| Режим (`mode`) | Текущий режим работы устройства |
| Охрана (`alarm_st`) | `норма` / `охрана` / `ТРЕВОГА` (при тревоге — пульсация и звук в браузере) |
| Батарея (`bat`) | Процент и напряжение, например `78% (3.95V)`; красный при low |
| Roll / Pitch | Углы наклона с MPU-6050 |
| Acc | Суммарное ускорение |
| LDR | `Темно` / `Светло` + уровень % и raw АЦП |

### Макеты интерфейса (`ui_theme`)

| Значение | Имя | Поведение |
|----------|-----|-----------|
| 0 | classic | Классические раскрывающиеся секции |
| 1 | hud | Горизонтальная карусель карточек + точки |
| 2 | tiles | Сетка плиток (по умолчанию). Тап — увеличение секции |
| 3 | orbit | Иконки сверху + панели снизу |

Подсказка в UI: *«Тап по плитке — увеличение. Тап вне — назад. Свайп влево/вправо. Центр — активная секция.»*

### Стили иконок (`ui_icon_style`)

| Значение | Имя | Описание |
|----------|-----|----------|
| 0 | soft (Neon Soft) | Мягкие SVG-иконки |
| 1 | bold (Neon Bold) | Более жирные линии |
| 2 | duo (Neon Duo) | Двухцветный стиль |

Во всех стилях есть отдельная иконка **фоторезистора (LDR)**.

### API

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/` | HTML страницы |
| GET/POST | `/api/config` | Чтение / сохранение настроек (`bike_config_t` → NVS) |
| GET | `/api/status` | Живой статус (батарея, LDR, углы, режим, тревога) |
| POST | `/api/command` | Команды: arm, disarm, calibrate, reboot, poweroff |

Кнопка **«Сохранить настройки»** отправляет текущие поля на `/api/config`.

## 2. Секции настроек (все 12)

### 🎛️ Управление (`ctrl`)

Команды управления устройством (через `/api/command`):

| Кнопка | Команда | Действие |
|--------|---------|----------|
| На охрану | `arm` | Постановка на охрану |
| Снять | `disarm` | Снятие с охраны |
| Калибровка | `calibrate` | Калибровка MPU-6050 (офсеты) |
| Ребут | `reboot` | Перезагрузка контроллера |
| Выключить | `poweroff` | Выключение питания (POWER_HOLD) |

---

### 💡 Габарит (`breath`)

| Параметр | ID | Диапазон (типично) | Описание |
|----------|-----|--------------------|----------|
| Период дыхания | `breath` | 0.5–6 с | Период плавного «дыхания» LEFT/CENTER/RIGHT |
| Яркость крайних | `side` | 0–100 % | Макс. яркость LEFT и RIGHT |
| Яркость центра | `center` | 0–100 % | Макс. яркость CENTER |

---

### 🛑 Стоп (`brake`)

| Параметр | ID | Описание |
|----------|-----|----------|
| Порог торможения | `brake` | Порог замедления (g) для срабатывания стоп-сигнала |
| Период мигания | `bper` | Период мигания при стопе |
| Длительность стопа | `bact` | Сколько секунд держать стоп после события |
| Яркость стопа | `bbr` | Яркость групп при стоп-сигнале, % |

---

### ↪️ Поворот (`turn`)

| Параметр | ID | Описание |
|----------|-----|----------|
| Мин. угол | `tmin` | Минимальный угол наклона для поворотника |
| Макс. угол | `tmax` | Максимальный угол (ограничение) |
| Удержание | `thold` | Время удержания угла перед включением |
| Время | `tact` | Длительность активного поворотника |
| Инверсия сторон | `invert` | Чекбокс: поменять лево/право |

---

### ⚠️ Авто (`auto`) — автоаварийка

| Параметр | ID | Описание |
|----------|-----|----------|
| Неподвижность | `stat_t` | Секунд тишины → включить MODE_HAZARD |
| Движение | `move` | Секунд движения → выключить аварийку |
| Чувств. тишины | — | 1–10: насколько «тихо», чтобы считать неподвижностью |
| Чувств. движения | — | 1–10: насколько заметное движение для выхода |

---

### 🔐 Охрана (`alarm`)

| Параметр | ID | Описание |
|----------|-----|----------|
| Порог | — | Порог движения (ускорение) для срабатывания |
| Подтверждение | — | Время подтверждения движения, с |
| Сирена | — | Длительность сирены, с |

В режиме охраны при движении — сирена + мигание; в UI статус «ТРЕВОГА» с пульсацией.

---

### 🌤 Фоторезистор (`ldr`)

| Параметр | ID | Описание |
|----------|-----|----------|
| Использовать | `ldr_en` | Вкл/выкл использование GL5528 |
| Порог темно | — | Порог «темно» 0–100 % |
| Гистерезис | — | Гистерезис 0–30 % (антидребезг порога) |
| Сейчас / Уровень | — | Живые значения: Темно/Светло, % и raw АЦП |

Влияет на режимы ленты и лазера (`dark_only`, `scale`, `brake_only_dark`).

---

### 🔴 Лазер (`laser`)

| Параметр | ID | Описание |
|----------|-----|----------|
| Режим | `las_mode` | 0 Выключен · 1 Всегда · 2 Только в темноте · 3 Стоп + темнота (по умолчанию) |
| Синхрон со стопом | `las_sync` | Мигать лазером вместе со стоп-сигналом |
| Яркость | `las_br` | 0–100 % |

При режиме off или 0 % — GPIO лазера LOW, канал ULN закрыт.

---

### ✨ Лента (`strip`)

| Параметр | ID | Описание |
|----------|-----|----------|
| Режим | `st_mode` | 0 Выключена · 1 Всегда · 2 Только в темноте · 3 Масштаб от света |
| Эффект | `st_eff` | 0 Дыхание · 1 Постоянный · 2 Аварийный стиль |
| Яркость днём | `st_day` | Обычно 0 % |
| Яркость ночью | `st_night` | Типично 80 % |
| Период | `st_per` | Период дыхания/мигания ленты, с |

В режиме аварийки лента работает без ограничения по LDR (безопасность).

---

### 🎆 Эффекты (`fx`)

| Параметр | Описание |
|----------|----------|
| Циклы вкл/выкл | Число циклов эффекта включения/выключения |
| Длит. цикла | Длительность одного цикла, с |
| Циклы охраны | Число циклов при постановке/снятии охраны |
| Длительность | Длительность эффекта охраны, с |

---

### 🔊 Звук (`snd`)

| Параметр | Описание |
|----------|----------|
| Громкость | 0–100 % (ШИМ зуммера) |
| Тон | Частота тона, Гц (типично ~2200) |
| Звуки интерфейса | Чекбокс `ui_snd` — звуки в браузере |
| Мелодия вкл | Выбор: Щелчки, Имперский марш, Включение, Выключение, Два бипа, Сирена, Перезвон |
| Мелодия выкл | Тот же список |
| ▶ Вкл / ▶ Выкл | Прослушать выбранную мелодию |

---

### 📡 WiFi (`wifi`)

| Параметр | Описание |
|----------|----------|
| SSID | Имя SoftAP (по умолчанию `BikeLight_AP`) |
| Пароль | Пароль точки доступа |
| Канал | Канал Wi‑Fi (по умолчанию 6) |
| Таймаут | Время простоя SoftAP до автовыключения, с (по умолчанию 300) |

После изменения SSID/пароля нужно сохранить и переподключиться к новой сети.

## 3. Связь с железом и логикой

- Настройки пишутся в NVS (`bike_config_t`). При несовпадении размера blob — defaults.
- LDR (GPIO0) и батарея (GPIO1) — общий `ADC_UNIT_1` (`adc1_shared`).
- Лента — **GPIO20**, лазер — **GPIO7**, LED_LEFT — **GPIO2** (см. описание проекта v2.6).
- Кнопка SW_MODE ≥ 8 с включает/выключает SoftAP; веб-интерфейс доступен только пока AP активен.
