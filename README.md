## 0. Инструменты разработки

Проект разрабатывался в следующем стеке:

| Инструмент              | Назначение                                      |
|-------------------------|-------------------------------------------------|
| **Blender**             | 3D-моделирование корпуса / визуализация         |
| **KiCad 9**             | Схема и печатная плата                          |
| **VS Code + PlatformIO**| Прошивка (ESP-IDF framework)                    |

Прошивка собирается и прошивается через PlatformIO (`platformio.ini`, board `esp32-c3-devkitm-1`, framework `espidf`).

## 1. Цель проекта

Создать устройство, которое:

- Работает от литиевого аккумулятора 18650 с BMS-платой, выдающей стабильные **+5 В**.
- Управляет четырьмя основными светодиодными каналами + лазерным каналом:
  - Левая группа (**LED_LEFT**)
  - Центральная группа (**LED_CENTER**)
  - Правая группа (**LED_RIGHT**)
  - Светодиодная лента (**LED_STRIP**)
  - Лазерный светодиод (**LASER**)
- Все силовые нагрузки (светодиоды + зуммер) управляются через **ULN2003A**.
- Имеет мониторинг заряда батареи с отображением в веб-интерфейсе.
- Имеет **фоторезистор GL5528** для автоматического управления лентой и лазером по освещённости.
- Выполняет функции:
  - Габарит — плавное «дыхание» основных групп
  - Стоп-сигнал — резкое мигание + лазер (по режиму и освещённости)
  - Поворотник — мигание крайней группы + звук
  - Аварийная сигнализация
  - Режим охраны
  - Автоматическая аварийка при длительной неподвижности
  - Светозвуковые эффекты включения/выключения и постановки/снятия с охраны
- Кнопка питания и кнопка режимов
- Яркость и громкость — ШИМ
- WiFi-интерфейс (удержание кнопки режимов ≥ 8 с) для настройки и мониторинга

## 3. Описание цепей и соединений

### 3.1. Силовая часть

- **BAT+** → вход BMS (BAT+).
- Выход BMS **5V+** → исток (S) Q1 (AO3401A).
- Затвор (G) Q1: R6 к 5V+, R7 к SW1 на GND, сток Q2.
- Сток (D) Q1 = шина **+5V**.
- Q2 (AO3400A): S → GND; G через R9 ← **GPIO21** (POWER_HOLD); R8 подтяжка G к GND.

### 3.2. Питание 3.3 В

Встроенный LDO модуля ESP32-C3 SuperMini.  
Вывод **3V3** питает MPU-6050 и делитель фоторезистора (R12 + LDR1).

### 3.3. Светодиоды и зуммер (ULN2003A)

Аноды LED от +5V через 120 Ом; катоды на открытые коллекторы ULN.  
COM ULN → +5V, GND ULN → общая земля.

| Канал ULN | Вход | GPIO      | Нагрузка     |
|-----------|------|-----------|--------------|
| 1         | I1   | GPIO5     | Зуммер       |
| 2         | I2   | GPIO4     | LED_RIGHT    |
| 3         | I3   | GPIO3     | LED_CENTER   |
| 4         | I4   | **GPIO2** | **LED_LEFT** (поворотник) |
| 5         | I5   | GPIO7     | LASER        |
| 6         | I6   | **GPIO20**| **LED_STRIP** |
| 7         | I7   | —         | не используется |

> **Редакция 2.6:** LED_STRIP перенесён с GPIO8 на GPIO20.  
> GPIO8 — strapping-пин: для Joint Download Boot (USB-прошивка) должен быть **HIGH**.  
> Нагрузка через ULN на GPIO8 срывала upload. GPIO8 **свободен**, не подключён к ULN.  
> LED_LEFT остаётся на GPIO2 (поворотник).

### 3.4. Мониторинг батареи

```
BAT+ ── R11 100к ──●── GPIO1 (ADC1_CH1)
                   │
                  R10 100к
                   │
                  GND  +  C6 150нФ
```

Делитель 1:2. При 4.2 В на ячейке на АЦП ≈ 2.1 В.

### 3.5. Фоторезистор GL5528

```
+3.3V ── R12 10к ──●── GPIO0 (ADC1_CH0)
                   │
                LDR1 GL5528
                   │
                  GND  +  C8 100нФ у GPIO0
```

- Светло → сопротивление LDR мало → напряжение на GPIO0 низкое → `ldr_percent` ближе к 0.
- Темно → сопротивление велико → напряжение высокое → `ldr_percent` ближе к 100.
- Без LDR (только R12) пин «плавает», raw ≈ 1500–2500 с шумом — норма до пайки датчика.

Оба аналоговых канала (батарея CH1, LDR CH0) используют **один** `ADC_UNIT_1` (модуль `adc1_shared`). Повторный `adc_oneshot_new_unit` для того же unit запрещён драйвером ESP-IDF.

### 3.6. Кнопки и MPU-6050

- SW1 → через R7 на затвор Q1.
- SW2 → GPIO6 (внутренняя подтяжка).
- MPU-6050: SDA = GPIO9, SCL = GPIO10, AD0 = GND, VCC = 3V3.

### 3.7. Сводная таблица GPIO

| GPIO      | Назначение    | Примечание |
|-----------|---------------|------------|
| GPIO0     | LDR (АЦП)     | ADC1_CH0 |
| GPIO1     | Батарея (АЦП)| ADC1_CH1 |
| **GPIO2** | **LED_LEFT**  | Поворотник (strapping, но не критичен как GPIO8) |
| GPIO3     | LED_CENTER    | |
| GPIO4     | LED_RIGHT     | |
| GPIO5     | BUZZER        | |
| GPIO6     | BUTTON_MODE   | |
| GPIO7     | LASER         | |
| **GPIO8** | **свободен**  | **Strapping — не нагружать ULN (критично для USB download)** |
| GPIO9     | I2C_SDA       | Strapping |
| GPIO10    | I2C_SCL       | |
| **GPIO20**| **LED_STRIP** | Перенесён с GPIO8 |
| GPIO21    | POWER_HOLD    | Удержание питания |

### 3.8. Прошивка

Прошивка по USB **без снятия ULN2003A**, пока GPIO8 не подключён к нагрузке.

При необходимости принудительного download: удержать BOOT (GPIO9), нажать RESET, отпустить BOOT.

Сборка и прошивка через PlatformIO:

```bash
pio run -t upload
pio device monitor
```

## 4. Принцип работы

- **Габарит** — дыхание LEFT / CENTER / RIGHT; лента и лазер — по своим режимам и LDR.
- **Стоп** — мигание основных групп; лазер — по `laser_mode`.
- **Поворотник** — крайняя группа + щелчки зуммера.
- **Аварийка** — мигание сторон; лента без ограничения LDR (безопасность).
- **Охрана** — тишина; при движении — сирена и мигание.
- **Автоаварийка** — неподвижность дольше порога → MODE_HAZARD.

### Режимы ленты (`strip_mode`)

| Значение    | Поведение |
|-------------|-----------|
| off         | Выключена |
| always      | Всегда (LDR не влияет) |
| dark_only   | Только в темноте |
| scale       | Яркость от уровня освещённости |

Дополнительно: `strip_effect` (дыхание / solid / hazard), яркость день/ночь, период.

### Режимы лазера (`laser_mode`)

| Значение           | Поведение |
|--------------------|-----------|
| off                | Выключен |
| always             | Всегда |
| dark_only          | Только в темноте |
| brake_only_dark    | Только при стопе и только в темноте (по умолчанию) |

При режиме `off` или яркости 0 % соответствующий GPIO в LOW → канал ULN закрыт → ток нагрузки ≈ 0.

## 5. Кнопка SW_MODE

| Удержание | Действие |
|-----------|----------|
| < 1 с     | Обычный ↔ Аварийный |
| 2–4 с     | Выключение питания |
| 4–8 с     | Постановка / снятие охраны |
| ≥ 8 с     | WiFi SoftAP вкл/выкл |

```c
#define PIN_LED_STRIP   20  /* перенесён с GPIO8 */

#define PIN_I2C_SCL     10
#define PIN_LDR          0
```

## 9. Заключение

Редакция **2.6**:

- ULN2003A на все силовые каналы LED + зуммер + лазер.
- POWER_HOLD — **GPIO21**.

| Яркость | `las_br` | 0–100 % |

При режиме off или 0 % — GPIO лазера LOW, канал ULN закрыт.

## 3. Связь с железом и логикой

- Настройки пишутся в NVS (`bike_config_t`). При несовпадении размера blob — defaults.
- LDR (GPIO0) и батарея (GPIO1) — общий `ADC_UNIT_1` (`adc1_shared`).
- Лента — **GPIO20**, лазер — **GPIO7**, LED_LEFT — **GPIO2** (см. описание проекта v2.6).
- Кнопка SW_MODE ≥ 8 с включает/выключает SoftAP; веб-интерфейс доступен только пока AP активен.
